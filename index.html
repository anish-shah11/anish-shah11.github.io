About

I am a PhD student in Computer Engineering at Indiana University Bloomington's Luddy School, where my research sits in high-performance computing — specifically GPU kernel design and performance engineering.

My work centres on performance characterisation across the stack: benchmarking GEMM implementations from naive C through CUTLASS on A100 hardware, profiling accelerator runtimes for on-device LLM inference on AMD Ryzen AI NPUs, and measuring cold-start behaviour in serverless systems. I am drawn to problems where a careful measurement changes what you believed about a system.

More broadly, I am interested in how architectural decisions — memory hierarchy, scheduling, data layout — translate into measured throughput on real hardware, and in building the simulators and benchmarks that make those effects visible.

Before starting my doctorate I spent eighteen months as a C++ developer at TechZest Global Solutions in Pune, working on cryptographic routines inside the OpenSSL framework and on low-level build and API issues. I hold a B.Tech in Electronics and Telecommunication Engineering from the Vishwakarma Institute of Information Technology, Pune.

Research Areas

GPU Kernel Engineering

Tiling, register blocking, and software pipelining for compute- and memory-bound kernels, evaluated against roofline models and hardware counters rather than wall-clock time alone.

Computer Architecture

Out-of-order execution, cache and memory hierarchy design, and branch prediction, studied through cycle-level simulators validated against real CPU traces.

Accelerator Runtimes

On-device LLM inference and serverless execution on NPU hardware — characterising runtime stacks, time-to-first-token, and cold-start latency under realistic load.

Performance Methodology

Profiling, roofline analysis, and hardware-counter instrumentation to establish where a workload actually spends its time, and which architectural limit it is bounded by.

GPU/CPU Matrix Benchmarking

Benchmarked seven GEMM implementations — naive C through OpenMP, MKL, OpenACC, CUDA, cuBLAS, and CUTLASS — on an A100 80GB, reaching 32,894 GFLOPS with CUTLASS (168× over baseline). Raised hand-written CUDA throughput 3.2× via tiling, register blocking, and software pipelining. Roofline analysis showed GEMV memory-capped near 350 GFLOPS; PAPI exposed a >10× cache-miss gap across loop orderings.

Local-to-Cloud LLM Cascade

A cascade prototype on an AMD Ryzen AI MAX+ 395 NPU using FastFlowLM via Lemonade's OpenAI-compatible API. Validated the XRT/XDNA stack and evaluated four GGUF models across cold-launch and warm streaming passes — Llama-3.2-1B sustained 10–12 ms warm TTFT. A FastAPI proxy serialises concurrent requests, logs queue-wait and service latency, and marks each request for local acceptance or cloud escalation.

Serverless Cold-Start Benchmarking

Characterised cold- and warm-start latency across eight CPU-inference and systems functions on an Iluvatar FaaS deployment running on Ryzen AI NPU hardware. Quantified the cold-to-warm gap (image_processing 1.414 s → 932 ms; imagenet 7.142 s → 6.271 s; hello 96 ms → 0.385 ms) and diagnosed duplicate HTTP/UnixSocket registration conflicts, isolating one function as a runtime return-path failure rather than measurement error.

Superscalar Out-of-Order Simulator

Cache and Memory Hierarchy Design

A configurable cache simulator sweeping eleven cache sizes across eight associativities, reaching a compulsory miss rate of 0.025 and an optimal average access time of 0.7342 under write-back write-allocate and LRU replacement policies.

RAID-5 Storage System Simulator
